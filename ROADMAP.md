# Pumblo feedback roadmap

This is the lightweight, public to-do list for useful creator and viewer feedback. New requests should be added here before implementation so they stay visible and can be evaluated against Pumblo's video-first product gates.

## Shipped from community feedback

- [x] Expand generation-tool suggestions, including Seedance 2.0, while allowing creators to leave the tool unspecified.
- [x] Add replies to video comments with reply notifications and readable threaded conversations.
- [x] Simplify navigation by removing decorative glyph icons.
- [x] Improve profile and Story Tier spacing and readability.
- [x] Increase the default interface scale to 110%.

## Next candidates

- [ ] Let creators edit or remove their own comments and replies.
- [ ] Add creator-controlled comment moderation tools.
- [ ] Add accessible transcript and caption uploads.
- [ ] Add optional per-video content notes for flashing imagery and sensitive themes.
- [ ] Add a compact roadmap link in the product once the feedback intake process is ready.

## How items move

Requests are checked for user value, safety, storage cost, accessibility, and fit with the AI-video-only scope. Accepted work moves into the shipped list with the implementation that completed it; declined or deferred ideas remain visible in the relevant issue or discussion rather than disappearing from the record.
